# MyEngineer Knowledge Database

## Назначение

MyEngineer — инженерная AI-система, которая соединяет:

- распознавание объектов;
- инженерные знания;
- CAD проектирование;
- материалы;
- технологии производства;
- реальные производственные мощности.

Система должна понимать не только "что это за деталь",
но и:

- как её улучшить;
- из чего её изготовить;
- на каком оборудовании её произвести;
- сколько это будет стоить.

# Главная цель

Создать первое персональное инженерное бюро с AI.


MyEngineer должен объединить:

- инженера-конструктора;
- технолога;
- дизайнера;
- производственника;
- исследователя.


Конечный сценарий:

Фото объекта →

AI анализ →

Инженерное решение →

CAD модель →

Выбор материала →

Выбор принтера →

Производство →

Готовый продукт.
