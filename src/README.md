# MyEngineer Core System


## Назначение

Папка `src` содержит программное ядро проекта MyEngineer.

Здесь будут находиться AI-агенты, которые превращают идею или фотографию объекта в инженерное решение и готовый продукт.

# AI Orchestrator


Главный управляющий модуль.


Задачи:

- принимает запрос пользователя;
- анализирует задачу;
- выбирает нужных AI-агентов;
- распределяет работу;
- объединяет результаты;
- формирует итоговое инженерное решение.


Пример:


Запрос:


Создать улучшенную деталь крепления автомобиля



Работа:



Orchestrator

↓

Vision Agent

Определяет оригинальную деталь

↓

Engineering Agent

Анализирует функцию и нагрузки

↓

CAD Agent

Создаёт 3D модель

↓

Material Agent

Выбирает материал

↓

Manufacturing Agent

Выбирает принтер

↓

Product Agent

Рассчитывает производство
