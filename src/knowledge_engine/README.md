# Engineering Knowledge Engine

## Purpose

Continuously updated engineering memory for MyEngineer.

The system collects and organizes:

- patents;
- technical documentation;
- datasheets;
- GitHub repositories;
- CAD resources;
- engineering references.

Pipeline:

```
PROJECT REQUEST
      ↓
DEEP RESEARCH AGENT
      ↓
SOURCE COLLECTION
      ↓
KNOWLEDGE MEMORY
      ↓
ENGINEERING AGENTS
      ↓
FINAL REPORT
```

Knowledge is project-specific and continuously expanded.
