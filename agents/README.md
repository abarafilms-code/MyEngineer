# MyEngineer AI Agents

Architecture of autonomous agents.

## Agents

### Vision Agent
Understands images, sketches, existing products and reverse engineering tasks.

### Research Agent
Finds analogues, patents, competitors and technical references.

### Engineering Agent
Creates technical concepts, calculations and component selection.

### Industrial Design Agent
Creates product identity, style direction and design briefs.

### CAD Agent
Prepares parametric CAD workflows and manufacturing geometry.

### Manufacturing Agent
Selects materials, production methods and cost strategy.
