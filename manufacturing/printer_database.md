# MyEngineer Printer Database

## Назначение

Этот раздел содержит цифровые паспорта производственного оборудования MyEngineer.

AI должен понимать:

- какой принтер выбрать;
- какой материал использовать;
- какую деталь можно изготовить;
- какие ограничения существуют;
- какую себестоимость имеет производство.
