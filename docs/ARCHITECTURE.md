# MyEngineer Architecture

## AI Agent System

```
                 MyEngineer Core

                      |

 ------------------------------------------------
 |              |              |                |
Research     Engineering     CAD        Manufacturing
 Agent          Agent        Agent          Agent

                      |

              Digital Product Model

                      |

        STEP / STL / BOM / Drawings
```

## Agents

### Research Agent

- finds analogues;
- analyzes technologies;
- searches patents;
- collects engineering knowledge.

### Engineering Agent

- creates requirements;
- selects components;
- proposes solutions;
- optimizes design.

### CAD Agent

- prepares 3D models;
- manages assemblies;
- generates technical documentation.

### Manufacturing Agent

- separates purchased and manufactured parts;
- selects production methods;
- prepares instructions.
